# RetinaScan

**Low-cost, on-device diabetic retinopathy screening for iPhone.**
Congressional App Challenge 2026 · PA-01 · Atharva Bhargude

RetinaScan analyzes a fundus image (a photo of the back of the eye) and tells you, in plain language, whether you should see an eye doctor for diabetic retinopathy. It checks image quality, runs a MobileNetV3 neural network entirely on the phone, and returns **Low / Moderate / Refer**.

> ⚠️ RetinaScan is a screening aid, **not a medical diagnosis**. It has not been validated on smartphone-lens images.

## Features
- On-device AI screening (Core ML), with no image upload
- Image quality gate: rejects blurry, dark or glare-filled images
- Low / Moderate / Refer triage with a model-score gauge
- Up to 5 profiles with saved scan history, a score-over-time chart and deletion
- "Ask RetinaScan" AI assistant (DeepSeek API) that explains saved results
- PDF report export · Find a nearby eye doctor
- Accessibility: English/Spanish, 4 text sizes, read-aloud, VoiceOver labels

## Results
| Evaluation | n | AUC | Sensitivity | Specificity |
|---|---|---|---|---|
| APTOS 2019 internal test | 586 | 0.992 | 0.958 | 0.963 |
| APTOS never-touched hold-out | 732 | 0.985 | 0.907 | 0.950 |
| Messidor-2 external (different hospitals/camera) | 1,744 | 0.844 | 0.414 | 0.971 |

- 5-class QWK 0.922 (APTOS test). Thresholds were chosen on the validation set only.
- External result: severe DR transfers well (86–91% of grade 3–4 flagged); moderate DR is the gap (26%).
- Robustness: 7 simulated phone-camera degradations × 3 severities. The quality gate recovers 88% of the AUC gap (excluding JPEG, which the app avoids by design).
- Deployment fidelity: Core ML (fp32) vs PyTorch max |Δprob| = 0.00001 on 60 golden images. fp16 was rejected (max 0.017).
